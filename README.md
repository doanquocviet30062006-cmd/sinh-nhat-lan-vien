# 🌌 The Birthday Universe | Handcrafted Luxury Birthday Website

A luxury, interactive, 7-stage cinematic birthday experience built with **React, TypeScript, Vite, Tailwind CSS, Framer Motion, HTML5 Canvas physics**, and a built-in **Web Audio API Ambient Synthesizer**.

## 🚀 The 7 Main Stages of the Experience

1. **Loading Universe Portal**: Starfield progress loader with audio activation button.
2. **Countdown Screen**: Translucent glassmorphism timer cards for **DAYS, HOURS, MINUTES, SECONDS** with purple-pink glow `#9D7BFF`, smooth flip numbers, and an instant preview button.
3. **Constellation Story**: Interactive 3D/Canvas star map connecting constellation points into milestone friendship quotes.
4. **Memory Journey**: Interactive memory photo timeline with glass cards, date badges, location tags, and tilt hover effects.
5. **Friend Achievement Gallery**: Fun "Badges of Honor" and certificates of friendship award with gold glass borders.
6. **Birthday Letter**: Luxury wax-sealed glass envelope that unfolds an handwritten birthday letter with typewriter atmosphere and floating sparkles.
7. **Secret Gift Room**: Interactive virtual birthday cake with blow-out candles feature and a secret unboxing gift box.
8. **Grand Celebration**: Fullscreen HTML5 canvas fireworks physics (gold, pink, purple, blue), city skyline silhouette, dynamic water reflections with ripple effects, floating confetti, and touch-to-fire interactive fireworks.

---

## 📁 How to Customize Content

All images, dates, recipient name, letter paragraphs, constellation points, achievements, and secret gifts are stored inside:

`src/data/birthdayData.json`

Simply edit the JSON file to update names, dates, photos, or messages without modifying code.

## 🛠️ Tech Stack & Scripts

- **React + Vite + TypeScript**
- **Tailwind CSS v4**
- **Framer Motion**
- **Web Audio API Synthesizer** (Zero external audio file dependencies)
- **Canvas-Confetti**

### Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build production bundle
npm run build
```
